## Marks 1.1.0

- OLED-black interface with softer, rounded bookmark rows and controls.
- Refined spacing, quieter separators, and a clear Save action.
- Visible keyboard focus and Enter support for bookmark rows.
- Fixed the add form remaining visible when it should be hidden.
- No new permissions. Existing bookmarks are unchanged.

### Install or update

Download `Marks-1.1.0.zip` and extract it to a permanent folder.
In `brave://extensions` (or `chrome://extensions`), enable Developer mode.
For a new installation, choose **Load unpacked** and select the extracted folder.
For an existing unpacked installation, replace the files in its original folder and press **Reload** on the Marks card. Downloading a ZIP alone does not update the installed extension.
