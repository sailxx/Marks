# Marks

Минималистичное расширение для Brave и Chrome: все закладки в одном окне — открыть, добавить, удалить. Без лишних плашек, светлая и тёмная тема по системе.

## Установка

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
2. Откройте `brave://extensions` (или `chrome://extensions`) и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку с `manifest.json`.

## Что умеет

- Клик — открыть в новой вкладке, Ctrl+клик или колёсико — в фоне.
- `✕` при наведении → «удалить?» → второй клик удаляет.
- «+ Добавить» внизу — форма с названием и адресом текущей вкладки, выбор папки.
- Новые закладки сверху, вложенные папки сворачиваются.

Разрешения: `bookmarks`, `activeTab`, `favicon`. Без сети и сбора данных.
